# Codex 운영 문서 안내

이 폴더는 매매전략이 아니라 실행 방법만 설명한다. 매매 판단은 루트의
`STRATEGY.md`만 따른다.

- `known-good-commands.md`: 테스트, 서버 접속, 배포, 정리 명령
- `vps-dashboard.md`: 서버 서비스와 대시보드 점검
- `ssh-powershell.md`: Windows PowerShell에서 서버 접속 명령이 꼬일 때
- `runtime-data.md`: 종이계좌 장부, 진단 자료, 저장공간 정리

현재 작업에 필요한 파일 하나 또는 해당 부분만 읽는다.
